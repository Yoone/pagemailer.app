Installation

Prerequisites

  • Ensure you are using Confluence Cloud, as PageMailer does not support server instances.

Installation Steps

1. Go to the Atlassian Marketplace

  • Visit the PageMailer app listing on Atlassian Marketplace.

  • Or directly from Confluence:

2. Install the app

  • Click Install or Try it free.
  • Authorize required permissions, such as:
    • Get Confluence page list and content
    • Access user profile (used for user mentions in pages)

3. Verify the installation

To ensure PageMailer was successfully installed, try to visit the app’s settings page, and make sure you are able to send an email.
